# 办公室模式：工位与空间利用率

只在用户选择办公室场景后读取本文件。共享的读图、包络、通道、确认、生图与验收流程遵循主 `SKILL.md`，本文件只补充办公室专属决策。

## 办公室专属输入

先确认 P1，并补齐会改变工位策略的信息：

- 总面积、净宽/净深、不可移动区域、可调整家具区，以及是否明确“不拆墙、不装修、不移门”。
- 现有桌椅尺寸、固定设备、储物需求，以及是否允许更换家具。
- 是否混合办公、共享工位是否可接受、哪些部门经常外出。
- 最大会议人数与频率，客户/候选人/供应商来访频率，是否需要等候区。

| 部门 | 当前人数 | 未来人数 | 必须固定开放区工位 | 独立办公室席位 | 可共享人员 | 可共享人员高峰同时到岗 |
|---|---:|---:|---:|---:|---:|---:|
|  |  |  |  |  |  |  |

如果没有完整数据，可建立模拟值，但必须逐项标为假设，并把结果标记为“规划级估算”。

## 决策顺序

1. **锁定硬约束**：墙、门、柱、独立办公室、会议室、茶水间、卫生间、消防及设备区默认不动。用户允许装修时，结构调整也应作为独立候选，不能混入零装修方案。
2. **按峰值配桌**：员工总数不等于桌数。固定设备、高频到岗及需保密岗位优先固定；经常外出或混合办公岗位可共享。共享位覆盖高峰同时到岗，而不是平均值。
3. **先画路线**：公共主线、员工次线、访客线先于工位。访客尽量不穿越研发、设计等安静或敏感核心区。
4. **再做邻接**：把协作频繁、设备共享或管理关系密切的部门放近；把高噪声、高来访与安静专注区分开。
5. **最后选择模块**：优先可调整的 4 人岛、6 人岛和少量独立共享位，不为整齐制造无效碎片。

### 常见邻接判断

- 行政人事：靠近入口、等候与会议室，缩短接待路径。
- 研发设计：相对完整、安静，减少公共人流穿越。
- 商务销售：靠近会议室和共享工位，适应外出与临时办公。
- 实习生/临时人员：靠近对应团队，不因“共享”被集中到远离直属团队的位置。

这些是初始判断，不是固定分区；真实协作频次和 P1 优先。

## 按 P1 取舍

- **空间利用率/承载人数**：先验证共享率和峰值，再增加模块化工位；不能通过压缩通道或缩桌换席位。
- **高频协作**：缩短高频团队间距离，保留邻近讨论点；不要让主通道穿过讨论核心。
- **安静专注**：减少公共路线穿越，拉开高噪声团队；允许牺牲少量席位。
- **访客接待**：入口、行政/前台、等候和会议室形成短路径，与核心办公区分离。
- **灵活扩编**：优先可拆分工位岛和共享位，展示当前与未来人数两套峰值校核。

## 容量计算

```text
固定开放区工位数 = 各部门必须固定开放区工位人数之和

共享工位需求 = 共享人员在同一高峰时段的同时到岗人数

总实体办公席位 = 固定开放区工位 + 共享工位 + 独立办公室席位

实体席位提升率 = (After 实体席位 - Before 实体席位)
                 / Before 实体席位 × 100%

员工/工位比 = 公司人数 / 总实体办公席位
```

部门高峰不同时，不把各部门各自峰值简单相加；优先使用同一时段数据。没有时段数据时明确采用了保守相加还是假设重叠率。

“可服务团队人数”包含轮换或共享，不得表述成“可同时坐下人数”；同时容量只等于当时可用的实体席位。

## 规划级家具与净距

真实家具尺寸优先；下列数值仅用于没有采购数据时的概念试排，最终按当地要求和实际产品复核。

| 项目 | 规划参考 |
|---|---:|
| 普通单人工位模块 | 1200 × 600 mm |
| 宽裕型单人工位模块 | 1400 × 700 mm |
| 4 人工位岛桌面组合 | 2400 × 1200 mm，含 4 个单人工位模块，2 对 2 |
| 6 人工位岛桌面组合 | 3600 × 1200 mm，含 6 个单人工位模块，3 对 3 |
| 椅子正常使用深度 | 650–750 mm |
| 次通道目标净宽 | ≥900 mm |
| 主通道目标净宽 | ≥1200 mm |
| 高频主通道目标 | 1400–1500 mm |

两侧都有人就座且中间需要通行时，按“椅子活动带 + 通行净宽 + 对侧椅子活动带”校核，不能只把两排桌之间标成 900 mm。

6 人岛必须对应 6 个 1200 × 600 mm 单人工位模块，或 3 个经确认的 1200 × 1200 mm 双面双人工位模块，不得虚报为 8 人岛。每个席位必须对应真实桌面宽度和一把椅子。

## 路线

- 公共主线：入口 → 前台/行政 → 会议室 → 茶水间。
- 员工次线：各工位岛 → 主通道 → 公共设施。
- 访客线：入口 → 等候 → 会议室；原则上不进入研发或敏感区。

检查门口和会议室/茶水间前的停留缓冲。路线连续不代表舒适；还需检查满员坐姿、两人错身和椅子拉出时的真实净距。

## 专项自检

- `固定开放区工位 + 共享位 + 独立办公室席位 = 总实体席位`；人员只归入其中一个席位类别。
- 图中桌数、椅数、岛型与文案完全一致。
- 共享位覆盖高峰，而不是只覆盖平均到岗。
- 椅子拉开后主次通道仍成立，桌椅不压门。
- 去会议室和茶水间不必无意义地穿越其他团队核心区。
- 访客路线不进入敏感区。
- 没有只能“看起来放得下”、实际无法入座或清洁的碎片工位。
- 所有估算项已标明，未将规划级结果冒充施工级结论。
